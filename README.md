## Now building

<a href="https://github.com/L1vsun/EDGERUN">
  <img src="https://raw.githubusercontent.com/L1vsun/L1vsun/main/assets/edgerun.png" width="100%" alt="EDGERUN - the post says buy, the wallet says sold. A browser extension that checks the token in the post you are reading." />
</a>

**[EDGERUN](https://github.com/L1vsun/EDGERUN)** is a browser extension for people who buy tokens off X. Under a post it says which mint the post really carries, who paid for the token's largest holders, and - when a public index knows the poster's wallet - what that wallet did before and after posting. It runs in the browser: no server, no account, no API key.

[Site](https://edgerun.pro) · [Source](https://github.com/L1vsun/EDGERUN) · [What each check means](https://github.com/L1vsun/EDGERUN/blob/main/docs/checks.md)
